Core concepts

Agents

An agent is a worker with one job. It has a start, steps, what it knows, and its rules.

The four that come with Kavedi#

AgentIts jobStarts
ReceptionistAnswers questions from what you taught itAny message no other agent took
BookerBooks, moves and cancels appointmentsWhen someone wants a booking
ReminderReminds people before their booking24 hours before, or when you choose
Follow-upChecks in with people who went quietAfter a number of quiet days

Switch each one on or off on the Agents page. Open one to change how it works.

While the Receptionist is on, every question someone sends gets an answer. If you only want some things answered, switch it off and build agents just for those.

Your own agents#

Describe what you want (“when someone asks how to pay, send my account details”) and press Build, start from a template, or start from scratch. See Create an agent.

Deleting one of the four#

Deleting the Receptionist, Booker, Reminder or Follow-up switches its setting off. Add back on the Agents page brings it back as it started.
