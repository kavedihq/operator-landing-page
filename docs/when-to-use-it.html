Build agents

When to use it

An agent takes a message by what it means, or on something exact.

By what they mean#

Write one sentence (“someone wants to order something”) and, if you like, examples of what people send. Any message that means it, in any words or language, is picked for this agent.

Use whole phrases as examples, never single words. An example that appears word for word in a message is taken straight away, so the example “book” would take every message with the word “book” in it.

By what they mean works for messages people send you, in chats with one person.

Words you send yourself#

Set Sent by to Me and words you type, like /hours, start the agent. You choose whether your message stays, turns into the reply, or is deleted. A / in front keeps it from going off in an ordinary message.

When it works and how often#

  • When it works: days and hours, during or outside them, in your time zone.
  • How often: every time, or at most once an hour, a day or a week for each person.
  • Another agent can answer too: only matters when this agent sends nothing, like an agent that only adds a label.
