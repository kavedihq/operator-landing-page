Build agents

Create an agent

Three ways to make one, all from the Agents page.

Describe it#

Type what you want in the box at the top (“when someone sends a photo of a payment, thank them and tell me”) and press Build. The assistant puts the agent together in front of you. Check it, then switch it on.

From a template#

Templates cover the common jobs: price list, opening hours, how to pay, “I’ve paid”, delivery, voice notes, someone wants to order. Open one, change the words, switch it on.

From scratch#

Every agent is the same four parts:

PartWhat it says
When to use itWhich messages it takes
StepsWhat it does, in order
Knowledge and rulesWhat it knows and what it must never do
Hand over to me whenWhen a chat comes to you

Test it before switching it on. See Test an agent.
