Troubleshooting

Fixes for the things people run into most.

It answers everything#

The Receptionist is on. Switch it off on Agents and build agents for just the things you want answered, or set people to Only you reply.

It answered a hello#

Open the agent, then Hand over to me when, and check Hellos and small talk is set to Stay quiet.

An agent didn’t answer#

  1. Is it switched on?
  2. Is it inside When it works, and outside its How often wait?
  3. Did you send something in that chat a moment before? Agents step back while you chat.
  4. Is the person waiting in your Inbox? Press Done.
  5. For an agent that starts by meaning, check its When to use it sentence describes the message.

The pairing code didn’t work#

Codes expire after a few minutes. Ask for a new one and type it under Link with phone number instead.

WhatsApp disconnected#

Settings, WhatsApp shows why. If Kavedi was removed from Linked devices on your phone, connect again.

Still stuck?#

Email support@kavedi.com or DM @kavedihq.
